What I Learned

Through this course on Software-Defined Radio (SDR) and Communication Systems Design, I got a better understanding of how communication 
systems work and how they can be designed and tested using software.

Key Learnings

Got a good understanding of the basic concepts of Software-Defined Radio (SDR) and how it is used in modern wireless communication.
Learned how a complete communication system works, starting from the transmitter and channel and ending at the receiver and signal-processing stages.
Worked with MATLAB to generate, process, visualize, and analyze different types of communication signals.
Developed a better understanding of Digital Signal Processing (DSP) and how it is used to process and improve communication signals.
Explored different modulation and demodulation techniques and implemented them using MATLAB simulations.
Gained practical exposure to concepts like sampling, filtering, frequency-domain analysis, and signal reconstruction.
Understood how noise and different channel conditions can affect a transmitted signal and the overall performance of a communication system.
Practiced creating and simulating basic transmitter and receiver systems using MATLAB/Simulink.
Learned why SDR is useful for communication systems, especially because it makes them flexible and easier to modify through software.
Became more comfortable working with signals in both the time and frequency domains and interpreting the results through plots and analysis.
One of the most useful parts of the course was learning to connect theory with practical implementation by turning communication concepts into simulations and experiments.
Along the way, started using Git and GitHub to keep the code organized, track changes, document experiments, and maintain the progress of the work.
Overall, this course gave me a practical foundation in SDR, communication systems, MATLAB, and signal processing and motivated me to explore more hands-on projects in wireless communication.

Overall Learning

Overall, this course helped me understand communication systems in a more practical way. Instead of only learning the theory, I was able to experiment with signals,
simulate different communication techniques, and see how the concepts work in practice.

It also gave me a stronger foundation in SDR, MATLAB, signal processing, and communication-system design, which I can build on through future projects and experiments.
